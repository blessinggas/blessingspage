Booster sequence  The learning plan — tap to open

At 3–5 hrs/day this whole set is done before the autumn deadline wave. Do them in this order so each cert is finished (or provably in-progress) before the application that needs it. Everything below is also a dated entry in the register.

Now · weeks 1–2 (early Aug) — foundation that gates everything
Portfolio + LinkedIn + CV fix · start Google UX Certificate (list as "in progress" immediately, chip away all autumn)
August · the UX×AI differentiators
Generative AI for UI/UX (IBM) · IxDF: AI for Designers · Google AI Essentials · one Figma course
Late Aug–early Sept · HCI credibility for the scholarships
IxDF: HCI Foundations (before Cambridge/Saclay proposals) · W3C Accessibility (for JP Morgan DDP) · start CS50 AI with Python
Sept–Oct · technical heavyweight + polish, alongside applying
CS50 Intro to CS (the long Harvard one, background) · book & sit French DELF/DALF so the cert lands before Entente Cordiale
Deliberately skipped: IBM UX cert & third UX cert (redundant with Google UX) · Adobe XD (being sunset for Figma) · CS50 Cybersecurity / 2D Games / Scratch (off-target for your applications) · standalone Product Design course (redundant) · the second Figma course (do one only). Doing all UX certs is the "wall of certificates" trap — one strong one is enough.
